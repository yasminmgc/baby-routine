## Codebase Patterns
### Backend (baby-routine-api/)
- Node.js/TypeScript/Express/Prisma/PostgreSQL stack
- Architecture: routes → controller → usecase → repository → schemas (Zod)
- Prisma 5.x, PostgreSQL peer auth, migrations in prisma/migrations/
- Tests with jest: `npm test` (unit in tests/unit/**, integration in tests/integration/**)
- Build: `npm run build` (tsc), typecheck: `npx tsc --noEmit`
- Auth/validation: Zod schemas → controller → use cases (throw AppError) → repository (Prisma)
- Sub-resource pattern: `Router({ mergeParams: true })` mounted at `/api/v1/babies/:babyId/...`
- Caregiver access: findCaregiver check on every baby-related endpoint → 403 if not
- Pagination: `{ data, pagination: { page, limit, total, totalPages } }`

### Frontend (baby-routine-app/)
- Flutter 3.22+ / Dart 3.4+ project in `baby-routine-app/`
- Architecture: Feature-First with layers — presentation → controllers (Riverpod) → repositories → data sources (Dio)
- State management: flutter_riverpod 2.x with AsyncNotifier
- Navigation: go_router 13.x declarative routing
- HTTP: dio 5.x with AuthInterceptor for JWT injection
- Models: freezed + json_serializable with build_runner code gen
- Colors: AppColors class with 12 constants (lilac palette + semantic)
- Font: Nunito via google_fonts
- Localization: intl package for pt-BR date formatting
- `.env` is gitignored; uses flutter_dotenv for environment config
- Auth controller pattern: `AsyncNotifier<void>` with `state = await AsyncValue.guard(() async { ... })` — guard catches sync/async errors into AsyncValue.error
- AsyncNotifierProvider for controllers that need to manage AsyncValue state; controllers that return lists directly use AsyncNotifier<void> with manual Future<T> return
- Repository provider: `final fooRepoProvider = Provider<FooRepository>((ref) => FooRepositoryImpl(ref.watch(dioClientProvider)))`
- Models: `@JsonSerializable()` from `json_annotation` with manually written `.g.dart` file containing `_$ClassNameFromJson` / `_$ClassNameToJson`
- Screens: `ConsumerStatefulWidget` + `GlobalKey<FormState>` for form validation
- Error extraction from Dio: dynamic property access with try/catch for `error.response?.data?.message`
- Widget tests for ConsumerStatefulWidget need `ProviderScope` wrapper; mock providers via `.overrideWithValue()`
- `Color.withOpacity()` used instead of `Color.withValues()` for Flutter 3.22 compatibility
- GoRouter global router variable: defined at module level (not in a Widget), accesses SecureStorage directly for redirect logic
- Redirect pattern: async (context, state) — check SecureStorage.getToken(), redirect unauthenticated from protected routes to /login, authenticated from public routes to /babies
- DioClient wraps Dio with BaseOptions (baseUrl, timeouts 10s, JSON headers), adds AuthInterceptor, exposes get/post/put/patch/delete
- AuthInterceptor: reads token from SecureStorage on every request via onRequest, clears token on 401 via onError
- Widget tests use `flutter_test` with `testWidgets`, wrap in MaterialApp+Scaffold for context
- Theme: ColorScheme.fromSeed(seedColor: AppColors.lilac), useMaterial3: true, GoogleFonts.nunitoTextTheme(), rounded InputDecoration (12px), full-width ElevatedButton (min 52px, lilacDark)
- Baby controller pattern: AsyncNotifier<void> for mutations (create/update/delete/addCaregiver/removeCaregiver) with AsyncValue.guard; list operations return Future<List<T>> directly to caller
- Screen data loading: call repository directly in ConsumerStatefulWidget methods (not via controller state), manage local _isLoading/_error state
- Home screen pattern: trigger initial AsyncNotifierProvider via `ref.read(provider)` in post-frame callback
- Checklist pattern: riverpod AsyncNotifier with build() that reads selectedBabyProvider; widget watches provider with .when(data:, loading:, error:)
- Pull-to-refresh: RefreshIndicator wrapping ListView, onRefresh calls controller.notifier.refresh()
- Event controller pattern: AsyncNotifier<void> for mutations (create/update/delete) with AsyncValue.guard; list/getById return Future directly to caller; reads selectedBabyProvider for babyId
- Event screens: ConsumerStatefulWidget + GlobalKey<FormState>, error extraction from DioException, success snackbar on completion, navigate to /home via context.go()
- Event screen pattern: try/catch around controller call, then check `ref.read(eventControllerProvider)` state for error/success (same as baby controller pattern)
- Time picker pattern: showTimePicker with 24-hour format, pt-BR locale override via Localizations.override, display formatted time via _timeLabel helper
- ChoiceChip pattern: Wrap widget with spacing 8, selected with lilacDark background and white text, unselected with white background and dark text
