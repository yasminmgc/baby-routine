## Codebase Patterns
### Backend (baby-routine-api/)
- Node.js/TypeScript/Express/Prisma/PostgreSQL stack
- Architecture: routes → controller → usecase → repository → schemas (Zod)
- Prisma 5.x, PostgreSQL peer auth, migrations in prisma/migrations/
- Tests with jest: `npm test` (unit in tests/unit/**, integration in tests/integration/**)
- Build: `npm run build` (tsc), typecheck: `npx tsc --noEmit`
- `tsconfig.test.json` (rootDir ".") for jest module resolution from test files
- Auth/validation: Zod schemas → controller → use cases (throw AppError) → repository (Prisma)
- Sub-resource pattern: `Router({ mergeParams: true })` mounted at `/api/v1/babies/:babyId/...`
- Caregiver access: findCaregiver check on every baby-related endpoint → 403 if not
- Pagination: `{ data, pagination: { page, limit, total, totalPages } }`
- Integration tests: --runInBand, cleanDatabase() in FK-safe order, supertest against app

### Frontend (baby-routine-app/)
- Flutter 3.22+ / Dart 3.4+ project in `baby-routine-app/`
- Architecture: Feature-First with layers — presentation → controllers (Riverpod) → repositories → data sources (Dio)
- State management: flutter_riverpod 2.x with AsyncNotifier
- Navigation: go_router 13.x declarative routing
- HTTP: dio 5.x with AuthInterceptor for JWT injection
- Models: freezed + json_serializable with build_runner code gen
- Colors: AppColors class with 12 constants (lilac palette + semantic)
- Font: Nunito via google_fonts
- Localization: intl package for pt-BR date formatting
- `.env` is gitignored; uses flutter_dotenv for environment config
- Flutter commands: `flutter pub get`, `flutter analyze`, `flutter test`, `flutter pub run build_runner build --delete-conflicting-outputs`
- GoRouter global router variable: defined at module level (not in a Widget), accesses SecureStorage directly for redirect logic
- Redirect pattern: async (context, state) — check SecureStorage.getToken(), redirect unauthenticated from protected routes to /login, authenticated from public routes to /babies
- DioClient wraps Dio with BaseOptions (baseUrl, timeouts 10s, JSON headers), adds AuthInterceptor, exposes get/post/put/patch/delete
- AuthInterceptor: reads token from SecureStorage on every request via onRequest, clears token on 401 via onError
- Widget tests use `flutter_test` with `testWidgets`, wrap in MaterialApp+Scaffold for context
- Theme: ColorScheme.fromSeed(seedColor: AppColors.lilac), useMaterial3: true, GoogleFonts.nunitoTextTheme(), rounded InputDecoration (12px), full-width ElevatedButton (min 52px, lilacDark)
